# 🛒 MERN Ecommerce Website

A full-stack ecommerce web application built using the MERN stack (MongoDB, Express, React, Node.js).  
Includes features like product management, bulk upload, authentication, and more.

---

## 🚀 Features

- 🛍️ Product listing & details page
- 🔐 User authentication (Login/Register)
- 🛒 Add to cart functionality
- 📦 Order management (basic)
- ⚡ Bulk product upload using CSV
- 🧑‍💼 Admin dashboard (optional)
- ☁️ Image upload support (optional - Cloudinary)

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- Bootstrap / Tailwind CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (Mongoose)
